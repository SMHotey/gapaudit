## Архитектурные инварианты (менять только через отдельный шаг с ревью)

1. **Порт** выбирает ОС: `socket.bind(("127.0.0.1", 0))`; порт не хардкодится.
2. **Токен сессии** `secrets.token_urlsafe(32)` генерируется в `desktop.py` при старте; все `/api/*`
   требуют его (заголовок `X-GapAudit-Token`, cookie `gapaudit_token` или query `?token=` — последнее для SSE).
3. **Host/Origin**: разрешены только `127.0.0.1:<порт>` и `localhost:<порт>`; иначе 403 (защита от DNS-rebinding).
4. **uvicorn — в демон-потоке**, `webview.start()` — только в `__main__` и только в главном потоке.
   Окно открывается после 200 от `/api/health` (ожидание до 10 с), иначе белый экран.
5. **Закрытие**: `server.should_exit = True` → `join(timeout=3)` → `sys.exit(0)`.
6. Ничего долгого в обработчиках: любая сетевая работа — подпроцессом через очередь задач, прогресс — SSE.
7. Данные приложения — в `data/` dev-режима и в `%USERPROFILE%\GapAudit-data\` (P4); в `AppData\Local\hermes` не писать.

   `CLI-CODE.md`, откуда таблица пришла, удалён 18.10.2026 — теперь таблица живёт здесь.

   | Файл | sha256 (12) | Строк | Байт |

   | `legacy/catalog_build.py` | `e98061593acc` | 286 | 14072 |
   | `legacy/catalog_scan.py` | `dda476f4c55e` | 126 | 6892 |
   | `legacy/check_predecessors.py` | `05eadcb96d13` | 405 | 18382 |

   Байты важны не меньше хеша: с CRLF те же файлы весили бы больше (`check_predecessors.py` — 18786 вместо 18382).
   От конвертаций защищает `.gitattributes` (`* text=auto eol=lf`, `legacy/** -text`); проверено клоном
   при `core.autocrlf=true` — байты и sha256 в клоне совпадают с таблицей.

   в скилл уезжает копия (`tools/sync_skill.py`, шаг P4) + `compat_check.py` как гейт перед коммитом.

4. **Кодировка — только UTF-8.** Файлы с кириллицей создавать/перезаписывать write-tool'ом, НЕ через
   PowerShell `Set-Content`/`Out-File` (cp1251). Дозапись — прочитать и перезаписать целиком.
5. **Комментарии, docstring'и, UI, README, отчёты — на русском.** Идентификаторы/пути/ключевые слова — как принято в коде.
6. **Git: без коммитов и пушей без прямого согласия пользователя.** Перед предложением коммита — `git status`.
7. **Секреты и токены не печатать в ответах** (кроме токена сессии dev-режима, он живёт минуты и нужен для отладки).
8. **Не выдумывать результаты.** Любое «работает» подтверждается выводом реально выполненной команды;

## Проверка перед завершением задачи (три способа, хотя бы один — живой прогон)

1. **Статика:** прочитать изменённые файлы, сверить с инвариантами выше, проверить импорты и пути (пути — абсолютные, не от cwd).

Формат отчёта: что сделано → вывод проверок → версии → проблемы → **явные отклонения от плана с причиной** → вопросы на ревью.

## Gotchas, проверенные на этой машине

1. `import pywebview` → `ModuleNotFoundError`; правильно — `import webview`.
2. `install_signal_handlers` в uvicorn 0.54.0 нет: `Server.capture_signals()` сам ничего не делает вне главного потока.
3. `TestClient` шлёт `Host: testserver` → любой `/api/*` вернёт 403 «недопустимый Host». Для позитивной проверки
   задавать `headers={"Host": "127.0.0.1:<порт>", "X-GapAudit-Token": "<токен>"}`.
4. Занятый порт: `ERROR: [Errno 10048] … bind` → через 10 с «/api/health не ответил», код выхода 1. Лечить
   повторным запуском без `--port` или другим портом, а не правкой кода.
5. Вывод `desktop.py`, перенаправленный в файл, буферизуется: для живого лога `PYTHONUNBUFFERED=1`.
6. Starlette 1.9.0 при импорте `TestClient` ругается «install httpx2 instead» — косметика, тесты проходят.
7. `confirm_close=True` показывает диалог «ОК/Отмена»; при автоматическом закрытии (WM_CLOSE) он наблюдается не всегда —
   поведение закрытия проверять глазами, если менялся.
8. Скриншоты проверок — `docs/screenshots/` (коммитятся). Рабочая папка `data/` в `.gitignore` целиком,
   кроме `data/.gitkeep`.
9. `.venv\Scripts\python.exe` (venv от uv) — лаунчер: `Popen.pid` ≠ `os.getpid()` внутри процесса.
   Для отслеживания PID задач (P1/P4) читать PID из stdout подпроцесса, не из `Popen.pid`.
10. WebView2: закрытие окна раньше ~2 с после старта даёт `E_ABORT (0x80004004)` — не дефект;
    в автотестах окна ждать инициализации (проверено: пауза 6 с — лог чистый).
11. Автотесты окна: искать строго по точному заголовку `GapAudit` И классу `WindowsForms10.*`;
    по подстроке — никогда: чужие окна (проводник, IDE, браузер) реагируют на `WM_CLOSE`.
12. Все текстовые файлы — LF (`.gitattributes`: `* text=auto eol=lf`; в системе
    `core.autocrlf=true`). Для сверки sha256 `legacy/` читать блоб, не рабочее дерево:
    `git cat-file -p HEAD:legacy/<файл> | sha256sum`.
13. `core.github.org_candidates` исправлен относительно legacy (`exclude_full_name` вместо мёртвой
    проверки `startswith(target+'/')`) — осознанное отклонение, зафиксировано паритетным тестом.
14. `core.registry.pypi_raw` устойчив к пустому `releases[ver]`: возвращает `date='?'`, а не `IndexError`
    (в legacy падало) — намеренная устойчивость.
15. **Появились файлы, которых вы не создавали, — стоп и `git log --oneline -5`.** Не коммитьте
    чужие изменения: параллельная запись в дерево — источник потери работы (single-writer).
16. **Перед коммитом — `git diff --cached --name-only` и явный `git add <свои файлы>`.** Не
    `git add -A`/`.`: IDE или параллельная сессия могут держать в индексе чужие файлы (1d).
17. Перезапись файла репозитория из Python — только `Path.write_text(..., newline="\n")`.
    Без этого на Windows в рабочем дереве появляется CRLF, а «Железное правило 1» ждёт LF.
18. Перед коммитом в P0+ — `uv run python -m tools.compat_check`: зелёный можно мержить,
    красный — сначала устранить расхождение. L1 — паритетные тесты, L2 — legacy
    (in-process) против new (subprocess) на тех же фикстурах; allowlist отклонений —
    `tools/compat_allowlist.py` (правка только с записью в DEVPLAN §4).
19. core/ не импортирует sqlite3 и не знает про app/. Персистентность живёт в app/store.py.
    CacheBackend protocol в core/cache.py — контракт, реализации: DictCache/FileCache (core, для CLI)
    и SqliteCache (app, для UI/jobs). При добавлении кэш-бэкенда — следовать этому правилу.
20. L2 в compat_check = in-process legacy + subprocess new. Для legacy-модулей с побочными
    эффектами на импорте (catalog_scan.py) — сравнивать с legacy-экстрактом из паритетного теста,
    не импортировать legacy-модуль.
21. sqlite3 с isolation_level=None: `with conn:` не коммитит.
    Нужен явный `BEGIN` + `with conn:` (так работает Store).
    Store потокобезопасен: self._lock вокруг публичных методов.
    JobQueue зовёт Store из воркеров — это безопасно.
22. Будущий MCP-сервер (P5) не хранит состояние: каждый tool —
    store.get_* / store.record_*. Никаких session_id в таблицах —
    MCP-сессия транспортная (stdio), данные принадлежат пакету и
    времени замера (run_id + measured_at). Store — единственный
    источник правды.
23. Тесты с реальными подпроцессами — под `@pytest.mark.slow`. Быстрый цикл
    (`-m "not slow"`) — только in-memory и tmp_path, без единого Popen; потолки
    времени — P-phase caps в DEVPLAN §11.
24. После `_finalized` никакие progress-апдейты не должны менять message/status:
    поздний progress затирает shutdown/error («прогресс 0.8, статус done»).
    Инвариант соблюдается в `JobQueue._handle_progress` под `self._lock`;
    в app/web.py (3b) SSE-подписчик не должен перезаписывать started после done.
25. При изменении контракта `/api/*` — сначала править `tests/test_web_middleware.py`
    (полный контур), потом `tests/test_web_smoke.py` (только сборка). Иначе соблазн
    расширять smoke: два описания контура расходятся при первой же правке.
26. POSIX-биты и Windows ACL проверяются по-разному: тест на chmod 0600 — `skipif Windows`,
    тест на icacls — Windows-only; оба живут в `tests/test_session.py`. На Windows
    `os.chmod` не трогает ACL (режим остаётся 0666), права даёт
    `icacls /inheritance:r /grant:r <domain>\<user>:F`.
27. desktop.py: shutdown порядок — window.events.closed -> queue.stop -> uvicorn
    should_exit -> remove_token -> exit(0). Если queue.stop не уложился в timeout —
    всё равно exit 0 (незакрытое окно хуже незавершённых процессов). E_ABORT при
    закрытии <2 с — не ошибка, ловить и exit 0. Подтверждение закрытия — в фоне:
    `evaluate_js` внутри обработчика closing вешает окно (deadlock UI-потока WebView2),
    поэтому обработчик возвращает False, а диалог идёт отдельным потоком.
28. `--browser` smoke-тесты обязаны выставлять `GAPAUDIT_NO_BROWSER=1`:
    иначе первый прогон открывает пользователю вкладку браузера (наблюдалось
    в 3c). desktop.py уважает env — проверять перед `webbrowser.open`.
29. Бюджеты тестов в DEVPLAN §11 — на «чистой машине» (без параллельных
    сборок). Под нагрузкой +25% допустимо. Гейт на абсолютное время без
    оговорки «clean machine» — ложно-красный. Сигнал регрессии — тренд
    fast-цикла между двумя подряд коммитами (> 20% — стоп).
30. GAPAUDIT_FAKE_HTTP=1 в cli/_common.py — тестовый бэкдор для сквозных
    тестов POST → CLI → SSE без сети. Фикстуры — tests/fixtures/http.
    В prod не выставляется. Если фикстур нет — RuntimeError, не тихий 404.
31. `_default_runner` запускает подпроцесс с `cwd=корень проекта`
    (`_PROJECT_ROOT` в app/jobs.py): `python -m cli.*` требует корень в
    `sys.path`, иначе запуск из произвольного cwd даёт `ModuleNotFoundError`.
    argv от cwd не зависит — это только рабочая директория процесса.
32. Порядок выключения в lifespan (`app/web.py`) — часть контракта:
    `queue.unsubscribe(хук)` → `post_executor.shutdown(wait=True)` → `queue.stop()` →
    `store.close()`. Записи наблюдений идут в пуле, поэтому `store.close()` раньше
    `shutdown` теряет последнюю задачу. Хук — пожизненный подписчик, значит
    `len(queue._subscribers)` в тестах не абсолют (SSE-тест сравнивает с baseline).
33. GAPAUDIT_FAKE_HTTP и GAPAUDIT_DATA_DIR из шелла живых прогонов остаются в окружении
    и ломают тесты (compat L2, CLI job-json): unset их после прогона. В
    tests/conftest.py — session-scoped autouse `_env_isolation` (сохранить GAPAUDIT_*,
    удалить на старте, восстановить на выходе); тестам с env — monkeypatch.setenv.
34. Тест на порядок вызовов без детерминированного триггера ложно-зелёный (race):
    перед коммитом сломать инвариант (перевернуть порядок, вставить задержку) и
    убедиться, что тест красный (3d-b: первый тест зелёный на перевёрнутом порядке,
    второй с задержкой 0.2 с ловит). Паттерн: «результат на диске» + «порядок
    вызовов с задержкой».
35. `git checkout -- <file>` откатывает к последнему коммиту, не к последней правке:
    незакоммиченное стирается, untracked не возвращается. Перед откатом — `git diff`,
    нужное — в `git stash`. Откат мутации теста — копией в scratch + обратным `cp`
    (так в 2b); `git checkout` в 2a съел локальную версию index.html.
36. Размер текстового файла считается в СИМВОЛАХ (`len(text)`), не в байтах: `wc -c`
    даёт байты, кириллица в UTF-8 — ~2 байта на символ, и цифра в отчёте выходит
    вдвое больше реальной. Ограничения на размер этого файла нет — правило осталось
    про единицу измерения.
37. Данные из вывода задач (stdout подпроцесса), имена пакетов и любые
    пользовательские строки — только через textContent / createTextNode /
    явное экранирование; innerHTML для них запрещён (XSS и сломанная вёрстка:

## AI Interaction Rules

- **Не додумывай — спрашивай:** неясен scope, величина или требование читается двояко — вопрос важнее догадки.
- **Один шаг — один ответ.** Не смешивать шаги плана в одном коммите; после шага — остановка на ревью.
